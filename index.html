功能

双板块汇总

课程资源目录树与单元学习全部单元一次读取，不必来回切换页面。

树状勾选

文件夹三态勾选，根目录文件也可单独选择；支持搜索与类型筛选。

类型筛选

PDF · PPT · Word · Excel · 压缩包 · 其他，按需过滤后再下载。

下载设置

可配置优先 ZIP / 始终批量、ZIP 内是否保留目录、体积与数量上限。

本地运行

使用你的登录会话读取已授权资源，不上传课件与账号信息。

清晰路径

ZIP 内按「课程资源 / 单元学习」分组，可选文件平铺，避免重复目录名。

下载方式

场景默认行为
常规选择（默认）打包为一个 ZIP，包内保留「课程资源 / 单元学习」目录
需要平铺文件设置 → ZIP 内目录 →「不要文件夹，文件平铺」
文件很多 / 体积很大自动改为批量逐个下载（可在设置中调整上限）
始终单文件或始终批量设置 → 打包方式 →「始终打包 ZIP」或「始终批量逐个」

压缩包文件名即课程名，例如 大学物理实验(II).zip；包内不再重复课程名目录。

常见问题

书签点了没反应？

请使用本页最新书签（复制或重新拖拽）。确认当前页是 course.buct.edu.cn 的课程页。若手动建书签，网址应以 javascript:(()=> 开头。

扫描结果里没有课程资源？

进入具体课程后点书签，工具会主动请求课程资源目录树。若仍为空，确认你有该课资源权限并刷新页面后重试。

如何不要文件夹、直接把文件放 ZIP 根目录？

面板 → 设置 → ZIP 内目录 → 选择「不要文件夹，文件平铺」→ 保存设置。

Chrome 询问是否允许多个下载？

批量模式下请点「允许」。使用 ZIP 时通常只触发一次下载。
